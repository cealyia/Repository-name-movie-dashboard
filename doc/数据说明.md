# 数据说明

## 一、数据来源

| 项目 | 内容 |
| --- | --- |
| 来源类型 | 开放数据集（真实用户行为数据，非模拟生成） |
| 数据集名称 | MovieLens Latest Small (`ml-latest-small`) |
| 发布机构 | GroupLens Research, University of Minnesota |
| 下载地址 | https://grouplens.org/datasets/movielens/latest/ |
| 获取日期 | 2026-11-06 |
| 数据生成日期 | 2018-09-26（数据集官方说明） |
| 原始文件 | `movies.csv`、`ratings.csv`、`tags.csv`、`links.csv`，均为 UTF-8 编码 |
| 原始行数 | 影片 9,742 / 评分 100,836 / 标签 3,683 |
| 时间跨度 | 1996-03-30 ~ 2018-09-24 |
| 用户数 | 610（已匿名化，不含任何个人信息） |

MovieLens 是明尼苏达大学 GroupLens 实验室维护的电影推荐研究数据集，被广泛用于推荐系统与数据可视化研究。
本数据集为 5 星制评分与自由文本标签，**不含用户人口学信息**，不涉及个人隐私。

## 二、数据模型

采用「维度表 + 事实表」的星型结构，共 5 张表：

```
dim_genre（类型维度）
      │
      ├── rel_movie_genre（影片-类型关联，多对多）
      │            │
dim_movie（影片维度）──── fact_rating（评分事实，10 万+ 行）
      │
      └────────────── fact_tag（标签事实）
```

| 表名 | 类型 | 行数 | 说明 |
| --- | --- | --- | --- |
| `dim_movie` | 维度表 | 9,742 | 影片基本信息 |
| `dim_genre` | 维度表 | 20 | 类型（19 个官方类型 + 未知） |
| `rel_movie_genre` | 关联表 | 22,084 | 一部影片可属于多个类型 |
| `fact_rating` | 事实表 | **100,836** | 一条记录 = 一个用户对一部影片的一次评分 |
| `fact_tag` | 事实表 | 3,683 | 一条记录 = 一个用户给一部影片打的一个标签 |

## 三、字段说明

### dim_movie（影片维度）

| 字段 | 类型 | 可空 | 含义 | 取值范围 / 说明 |
| --- | --- | --- | --- | --- |
| movie_id | INT | 否 | 影片 ID，主键 | 与 MovieLens movieId 一致 |
| title | VARCHAR(300) | 否 | 片名（含上映年份） | 例如 `Toy Story (1995)` |
| release_year | SMALLINT | 是 | 上映年份 | 1902–2018；13 部无法解析时为 NULL |

### dim_genre（类型维度）

| 字段 | 类型 | 可空 | 含义 | 取值范围 |
| --- | --- | --- | --- | --- |
| genre_id | INT | 否 | 类型 ID，主键 | 1–20 |
| genre_name | VARCHAR(20) | 否 | 中文名 | 动作、喜剧、剧情…… |
| genre_name_en | VARCHAR(30) | 否 | 原始英文名 | Action、Comedy…… |
| sort_no | INT | 否 | 展示顺序 | 1–20 |

### rel_movie_genre（影片-类型关联）

| 字段 | 类型 | 可空 | 含义 |
| --- | --- | --- | --- |
| movie_id | INT | 否 | 影片 ID，外键 → dim_movie |
| genre_id | INT | 否 | 类型 ID，外键 → dim_genre |

联合主键 `(movie_id, genre_id)`，一部影片平均 2.27 个类型。

### fact_rating（评分事实表，核心表）

| 字段 | 类型 | 可空 | 含义 | 说明 |
| --- | --- | --- | --- | --- |
| rating_id | BIGINT | 否 | 记录 ID，主键 | 1–100836 |
| user_id | INT | 否 | 用户 ID | 1–610，已匿名 |
| movie_id | INT | 否 | 影片 ID，外键 | → dim_movie |
| score | DECIMAL(3,1) | 否 | 评分 | **10 分制**，原始为 5 星制 × 2 |
| rated_at | DATETIME | 否 | 评分时间 | 按东八区换算 |
| rated_date | DATE | 否 | 评分日期 | 冗余列，用于按天聚合 |
| rated_month | CHAR(7) | 否 | 评分月份 | 冗余列，格式 `yyyy-MM` |
| rated_year | SMALLINT | 否 | 评分年份 | 冗余列 |

> `rated_date` / `rated_month` / `rated_year` 是导入时从 `rated_at` 派生的冗余列，
> 目的是让「按月趋势」这类查询可以直接走索引，避免每次都对 10 万行做 `DATE_FORMAT`。

### fact_tag（标签事实表）

| 字段 | 类型 | 可空 | 含义 |
| --- | --- | --- | --- |
| tag_id | BIGINT | 否 | 记录 ID，主键 |
| user_id | INT | 否 | 用户 ID |
| movie_id | INT | 否 | 影片 ID，外键 |
| tag | VARCHAR(100) | 否 | 标签文本，已 trim |
| tagged_at | DATETIME | 否 | 打标签时间 |
| tagged_date | DATE | 否 | 打标签日期 |

## 四、清洗规则与影响行数

| # | 规则 | 处理方式 | 影响行数 |
| --- | --- | --- | --- |
| 1 | 片名解析上映年份 | 正则 `\((\d{4})\)$` 取末尾括号年份；解析失败**不删除记录**，`release_year` 置 NULL | 13 部（评分记录全部保留） |
| 2 | 评分值域校验 | 原始应为 0.5–5.0 星；越界记录剔除 | 0 条 |
| 3 | 重复评分校验 | 同一 `(user_id, movie_id)` 只保留一条 | 0 条 |
| 4 | 评分制式统一 | 5 星制 ×2 转为 10 分制，保留 1 位小数 | 100,836 条全部转换 |
| 5 | 时间字段派生 | 时间戳（UTC）按东八区转换为 `rated_at`，再派生 `rated_date`、`rated_month`、`rated_year` | 100,836 条 |
| 6 | 类型名称标准化 | 英文类型映射为中文；`(no genres listed)` 统一为「未知」 | 20 个类型值，0 条未知取值 |
| 7 | 标签清洗 | 去除首尾空格；空标签剔除 | 0 条空标签 |
| 8 | 外键完整性 | 评分 / 标签中的 `movie_id` 必须存在于 `dim_movie` | 0 条孤儿记录 |

**最终入库行数：102,522 条业务数据**（评分 100,836 + 标签 3,683 + 影片 9,742 +
类型关联 22,084 + 类型 20），其中核心事实表 100,836 行。

## 五、为什么这些数据可以支撑看板

| 看板需求 | 数据依据 |
| --- | --- |
| 时间趋势 | `rated_at` 跨 22 年，可按天/月聚合出评分活跃度曲线 |
| 分类对比 | `dim_genre` + `rel_movie_genre` 支持 20 个类型的横向对比 |
| 占比分布 | `score` 可做评分区间分布，`movie` 可做类型占比 |
| TOP 排行 | 按 `COUNT(rating_id)` 或 `AVG(score)` 排序 |
| 词云 | `fact_tag.tag` 为真实用户标签，共 3,683 条 |
| 地理/年代分布 | `release_year` 支持年代 × 类型热力图 |

## 六、已知局限

1. MovieLens 数据集**不包含导演、演员、简介**等字段，因此本项目未提供导演维度的分析，
   作品信息以「片名 + 上映年份 + 类型 + 标签 + 评分」为主。
2. 数据止于 2018-09-24，看板展示的是历史数据，不代表当前电影市场。
3. 用户数为 610，属于小样本，类型维度的平均分波动较大（部分类型只有几十条评分）。
   因此页面上同时展示「影片数」和「评分数」，避免只看平均分造成误读。
